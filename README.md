# 🎮 Juego Piedra, Papel o Tijera
Bienvenido al repositorio del **Juego de Piedra, Papel o Tijera** 
--- 
## 🎯 Objetivo del Sistema 

El objetivo de este programa es proporcionar una plataforma interactiva y entretenida en Python que permita a un usuario enfrentarse contra la computadora en el clásico juego de "Piedra, Papel o Tijera", aplicando controles de vidas y validaciones de datos para garantizar una ejecución fluida y libre de errores de entrada. 
--- 
## 🚀 Funcionalidades Principales 
- 👤 **Personalización de Usuario:** Registro del nombre del jugador al iniciar la partida. 
- ❤️ **Sistema de Vidas:** Configuración de la cantidad de vidas iniciales seleccionada por el usuario. 
- 🛡️ **Validación de Entradas:** Control de errores si el usuario digita texto no válido o caracteres incorrectos. 
- 🤖 **Turno Aleatorio de la Computadora:** Elección aleatoria de opciones mediante la librería `random`. 
- 📊 **Conteo e Historial de Ronda:** Descuento automático de vidas y visualización del estado actual tras cada jugada. 
- 🏆 **Declaración de Ganador:** Notificación clara cuando alguno de los dos participantes se queda sin vidas. 
--- 
## 🛠️ Herramientas y Tecnologías Utilizadas 
- 🐍 **Lenguaje de Programación:** Python 3 
- 💻 **Entorno de Desarrollo (IDE):** Visual Studio Code 
- 📦 **Control de Versiones:** Git & GitHub 
--- 
## 📋 Estructura del Código 
El proyecto hace uso de: 
- **Estructuras Condicionales (`if`, `elif`, `else`):** Para la evaluación de respuestas y determinación del ganador. 
- **Estructuras Repetitivas (`while`, `for`):** Para el control de vidas y reintento de entradas inválidas. 
- **Colecciones (Listas, Tuplas y Diccionarios):** Para almacenar las opciones válidas y la lógica de combinaciones de juego.
